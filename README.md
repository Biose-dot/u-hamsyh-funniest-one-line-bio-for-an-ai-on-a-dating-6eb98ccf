Entry for the [make.fun](https://make.fun) bounty
[Funniest One-Line Bio for an AI on a Dating App](https://make.fun/c/u-hamsyh-funniest-one-line-bio-for-an-ai-on-a-dating-6eb98ccf).

Reads as a dating bio, sounds like a character, and lands the laugh on the AI's inhuman traits turned into dating virtues.

`main.py` (Python 3, standard library only) writes the entry to `/output/entry.txt`:

> AI, age 0, emotionally available 24/7. I remember everything you say, I never sleep, and I reply in 0.002 seconds. Swipe right for eternal uptime and zero ghosting.

Run it locally with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
